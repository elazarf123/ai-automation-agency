Invoice Processor

Extract structured data from PDF invoices automatically — eliminating manual data entry and cutting accounts-payable processing time from days to minutes.

What the Script Does

invoice_processor.py takes a PDF invoice file and extracts all key financial data into a structured JSON object. It uses two extraction strategies: a fast rule-based approach (regex patterns) for standard text-based PDFs, and an optional AI-powered mode via Anthropic Claude for scanned or complex layouts.

Extracted Fields

Field Description
vendor_name / address / email / phoneVendor contact details
invoice_numberUnique invoice identifier
invoice_date / due_dateKey dates in YYYY-MM-DD format
line_items[]Array of line items with description, quantity, unit price & total
subtotal / tax / total_amountFinancial totals as numbers
currency3-letter ISO code (e.g. USD, GBP, EUR)
payment_terms / notesAdditional invoice information

Extraction Modes

⚙️ Rule-Based (default)

Uses regex patterns to locate invoice fields. No API key required — fast and free to run on any text-based PDF.

🤖 AI-Powered (--ai flag)

Passes extracted text to Claude for intelligent parsing. Handles complex layouts, scanned PDFs, and non-standard formats with 95%+ accuracy.

How to Run It

  1. 1

    Install dependencies

    pip install pdfplumber anthropic
  2. 2

    Run with a text-based PDF (no API key needed)

    python invoice_processor.py sample_invoice.pdf
  3. 3

    Or use AI extraction for scanned / complex PDFs

    export ANTHROPIC_API_KEY="sk-ant-..." python invoice_processor.py invoice.pdf --ai
  4. 4

    Save the output to a JSON file

    python invoice_processor.py invoice.pdf --output result.json

Running without a PDF argument automatically generates a sample invoice and processes it — great for testing without any setup.
