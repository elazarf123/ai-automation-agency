AI Lead Qualifier

Automatically score and grade inbound business leads using Anthropic Claude, so your sales team focuses only on the hottest prospects.

What the Script Does

lead_qualifier.py accepts structured lead data (name, company, message, industry, size, etc.) and sends it to Claude via the Anthropic API. The model evaluates each lead across five dimensions and returns a structured JSON result with a numeric score, letter grade, and recommended next action.

Scoring Dimensions

  • 1. Company Fit — industry relevance and company size
  • 2. Budget Signals — explicit or implied budget mentions
  • 3. Urgency — timeline requirements and pain-point language
  • 4. Decision-Maker — is the contact the right person to buy?
  • 5. Automation Need — are there clear manual workflows to replace?

Output Format

For each lead the script returns a JSON object containing:

Field Description
scoreInteger 0–100
gradeA / B / C / D letter grade
summary2–3 sentence plain-English overview
strengthsList of positive signals
weaknessesList of disqualifying factors
next_stepSpecific recommended sales action
estimated_deal_sizesmall / medium / large / enterprise

Grading Rubric

A

90–100 · Hot lead
Contact within 1 hour

B

70–89 · Warm lead
Contact within 24 hours

C

50–69 · Nurture
Add to email sequence

D

0–49 · Disqualify
Park for 90 days

How to Run It

  1. 1

    Install the dependency

    pip install anthropic
  2. 2

    Set your API key (optional — runs in mock mode without it)

    export ANTHROPIC_API_KEY="sk-ant-..."
  3. 3

    Run the script

    python lead_qualifier.py

The script ships with three sample leads. You can also import qualify_lead() directly to score leads programmatically in your own application.
