What the Script Does

support_bot.py loads a folder of Markdown or text files as its knowledge base, then enters an interactive chat loop. Each time a user asks a question, the bot finds the most relevant documents using a built-in TF-IDF retrieval engine and either generates an AI response via Claude (when an API key is set) or returns a canned offline answer — no external vector database needed.

How It Works — Step by Step

  1. 1
    Load knowledge base — reads all .md and .txt files from the knowledge_base/ directory (or a custom path).
  2. 2
    Build TF-IDF index — calculates term frequency–inverse document frequency scores across all documents so it can rank relevance quickly without any external libraries.
  3. 3
    Retrieve context — for each user question, retrieves the top-3 most relevant document sections.
  4. 4
    Generate answer — passes the retrieved context and full conversation history to Claude, which produces a concise, grounded response. Falls back to keyword-matched canned responses in offline demo mode.
  5. 5
    Loop — keeps the conversation going, maintaining history across turns (up to the last 10 exchanges).

Key Features

  • ✓ Zero external dependencies for retrieval — pure Python TF-IDF
  • ✓ Works offline in demo mode with no API key required
  • ✓ Bring your own knowledge base — just drop Markdown files in a folder
  • ✓ Maintains multi-turn conversation history
  • ✓ Supports non-interactive mode for piping questions from stdin
  • ✓ Ships with a default AutomateIQ knowledge base (services, pricing, FAQ, contact)

How to Run It

  1. 1

    Demo mode — no API key needed

    python support_bot.py
  2. 2

    Live AI mode with Claude

    export ANTHROPIC_API_KEY="sk-ant-..." python support_bot.py
  3. 3

    Use a custom knowledge base directory

    python support_bot.py --kb ./my_knowledge_base
  4. 4

    Non-interactive mode — pipe a question in

    echo "What is your refund policy?" | python support_bot.py --once

The anthropic package is optional — install it only if you want live Claude responses. Run pip install anthropic to enable AI mode.
